Title of Project: Car Crash Analysis

Description: 
My project has two main components, the first being a simple algorithm that analyzes the features of Charlotte's public car crash dataset retrieved 
from the City of Charlotte website(https://data.charlottenc.gov/datasets/e48e2174b51040dca22e9aec4fd894f6_0/explore?location=37.769050%2C-77.857900%2C4). The code has numerous useful features, such as providing information on the most frequent car crash months, or 
what major holidays have statistically significant car crash rate increases.

The second part of my project is a neural network made from the  library, which is made from the combined database of the Charlotte car crash dataset referenced earlier an
a database retrieved from the open source Visual Crossing website(https://www.visualcrossing.com/weather-query-builder/charlotte/?v=wizard). The AI merges both 
datasets in order to predict how severe a crash will be with a few parameters(such as precipitation, day of the week, and type of crash). The AI can also assess the general risk
of driving under certain conditions(the same parameters, but without the biggest factor, type of crash, so weather would have a larger impact). 

My project is useful, since it can be used for safety purposes: first, it gives drivers an idea of how dangerous the conditions for driving are. It is evidently important 
that drivers remain alert regardless of weather or road conditions, but it could help at-risk drivers, such as new learners, elderly, and impaired drivers gauge whether it
safe for them to drive. 

The results from the code analysis and neural network could also be used by the City of Charlotte to map out the most car-crash concentrated months and use that data to try and 
implement measures to improve safety during those months. 

Installation instructions: clone the repository and open the car_crash_analysis file on VScode. Run the Post_Car_Crash_Analysis neural network on Google Colab for the best
results.
